# 🏡 StayHub

StayHub is a full-stack web application inspired by platforms like Airbnb, allowing users to discover, list, and book unique stays. It provides a seamless experience for both travelers and hosts with secure authentication and dynamic property listings.

# 🚀 Features
	•	🔐 User Authentication (Login / Signup)
	•	🏠 Create, Edit & Delete Listings
	•	📍 Explore stays with location & pricing
	•	🖼️ Image upload for listings
	•	👤 User ownership & authorization
	•	⭐ Reviews & ratings system
	•	📦 MongoDB database integration
	•	🌐 Fully responsive UI

StayHub aims to provide a simple and user-friendly booking experience similar to modern rental platforms.
